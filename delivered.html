How fields are filled, and Length of Video options
  • Task Name: the file name without its extension.
  • Project Name: the first four parts of the file name (26_LVE_BXPW_BREITIsBack), unless you type one above.
  • Aspect Ratio: the display size, corrected for rotated and anamorphic footage, written as 16x9, 9x16, 1x1, 4x5 and so on.
  • Quality: 4K when the short side is 2000 pixels or more, HD from 720, otherwise SD.
  • File Path: the folder path you paste above plus any subfolders inside it.
  • SRT file delivered?: Yes when an .srt with the same name sits beside the video.
  • A yellow dot means some details couldn't be read. A red dot means the file couldn't be read. Type missing values into the table.
