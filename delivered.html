Delivered.

Add finished deliverables and get their details as rows you can paste into Smartsheet. Files are read on this computer and never uploaded.

Browsers can't see full file paths. Mac: right-click the folder, hold Option, choose "Copy … as Pathname". Windows: Shift + right-click, "Copy as path".
Drop video files or a folder here
MOV, MP4 and M4V are read in full, including ProRes. Other formats get whatever the browser can read.
Columns
Example rows. Add your files to replace them.
In Smartsheet, click the first empty cell in the first column, then paste. Click any cell above to fix it before copying.
How each field is found
  • Project name: what you type above, or else the name of the folder you added.
  • File location: the path you paste above plus any subfolders inside it.
  • Length, resolution, frame rate, codec: read from the file's header, so large files load instantly.
  • Aspect ratio: the display size, corrected for rotated phone footage and anamorphic pixels, matched to the nearest standard ratio (16:9, 9:16, 1:1, 4:5, 2.39:1…).
  • A yellow dot means some details couldn't be read. A red dot means the file couldn't be read. You can type the missing values in.
